## About Me

I study robotics at **Inha University**, bringing together mechanical design, embedded electronics, and control engineering. My work ranges from legged robots and assistive manipulators to dynamic simulation and machine learning.

My flagship project is the **RRC Hexapod Robot**, a modular disaster-response platform. I am interested in building systems that connect physical mechanisms, real-time control, and intelligent behavior.

## Featured Projects

| Project | Overview & Contributions |
| --- | --- |
| [**RRC Hexapod Robot**](https://github.com/robot-research-club-rrc/HEXAPOD-ROBOT) | **My flagship project.** Modular 18-DOF disaster-response hexapod. Work spans tripod gait, 3-DOF inverse kinematics, Bézier foot trajectories, STM32 locomotion control, and a Jetson–STM32 distributed architecture, with MATLAB/Simulink evaluation and a residual reinforcement-learning design. |
| [**A.R.M.S. — Anti-drone Reusable Modular System**](https://github.com/tokhun2002/A.R.M.S.-Anti-drone-Reusable-Modular-System-) | Reusable modular counter-drone platform. Contributed to hardware integration, control-system testing, and net-module development, including spring-release modeling and ELRS communication testing. |
| [**LUMEN Meal Assist Robot**](https://github.com/kimsh039/Meal-Assist-Robot) | Multi-joint robotic arm for independent eating. Developed the control system, Arduino board communication, actuator control, and sensor/interface integration; repository includes servo and Dynamixel control, inverse kinematics, and motion sequences. |
| [**CartPole: PID · MPC · PPO**](https://github.com/kimsh039/cartpole-pid-mpc-ppo) | Compared classical, model-based, and reinforcement-learning controllers on a nonlinear CartPole. MATLAB modeling and Monte Carlo evaluation, with PyBullet trajectory visualization. |
| [**DS51150 Manipulator**](https://github.com/kimsh039/DS51150-Manipulator-MATLAB-IK) | Analytical inverse kinematics and trajectory simulation for an Arduino-controlled manipulator, with joint-limit checks, forward-kinematics validation, and servo PWM conversion. |
| [**IN:AIR Net Module Spring Release**](https://github.com/kimsh039/INAIR-ARMS-Net-module-spring-release) | Designed a spring-powered deployment mechanism in Fusion 360 and evaluated spring candidates using a two-degree-of-freedom dynamic model, cross-checked in MATLAB and Simulink. |
| [**Eastar Jet On-Time Performance Improvement**](https://github.com/kimsh039/Eastar-Improved-punctuality) | Maintenance-delay prediction study. Selected and trained an MLP classifier with SMOTE and analyzed recall/false-positive trade-offs under severe class imbalance. |
| [**SAERO Fire Capsule**](https://github.com/kimsh039/Fire-Capsule-Project) | Led a wildfire-detection capsule concept project. Developed Arduino firmware and hardware wiring concepts for temperature-triggered wake-up, GPS, LoRa, EEPROM, and Kalman filtering; current public code is a firmware prototype. |
| [**Mathematics Academy Parent Platform**](https://github.com/wwer1144/rtm-math) | Developed and operated a parent-facing web platform for Park Wonwook Mathematics Academy, contributing to implementation, maintenance, and deployment. |
