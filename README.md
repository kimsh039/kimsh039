# Sean Kim

인하대학교에서 기계공학과 전기전자공학을 복수전공하며, 실제 하드웨어에서 동작하는 로봇 제어 시스템을 만들고 있다. 기구 설계부터 회로·임베디드 펌웨어·제어 알고리즘·시뮬레이션까지 한 시스템으로 연결하는 작업에 관심이 있다.

## Focus

- Robot mechanism design and actuator control
- STM32 / Arduino embedded systems
- MATLAB, Simulink and control-system simulation
- Fusion 360 and hardware prototyping
- Legged robots, manipulators and drones
